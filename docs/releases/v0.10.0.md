# Winglet v0.10.0

Rooms in Projects, clearer approval controls, and custom MCP connections.

- **File Rooms in Projects.** Move a Room into a shared project belonging to one
  of its bots, remove it from the project, or start a Room from the project.
  Moving or deleting the folder keeps the Room and its messages. Room access
  rules still apply. Updated servers refresh the project list on changes;
  older servers retain polling while the project is open.
- **Allow everything in one chat.** Owners can confirm this on an ordinary
  approval card. It approves the current command and lets later commands in
  that chat run without asking until approvals are turned back on or the
  Hermes session ends. A warning banner provides **Turn back on**. Hermes's
  hardline blocks and configured deny rules still apply. Rooms are excluded.
- **Clearer Smart approval cards.** A command blocked by the Smart guardian
  offers only **Allow once** or **Deny**, with an explanation. It cannot enable
  the chat approval bypass.
- **Add your own MCP server.** Owners can add remote HTTP servers with no
  authentication or a sealed header key, and local commands with sealed
  environment values and an explicit command review. HTTPS is required except
  for loopback/private LAN addresses. Custom OAuth setup is deferred because
  sign-in cleanup and server-name reuse need further validation; configure
  custom OAuth through Hermes. Existing catalog OAuth remains available.
- **View skill sources.** Official catalog skills and installed hub skills
  show source links where safe provenance is available. Installation from an
  arbitrary URL remains deferred until Hermes supports exact-source installs.
- **Safer URL decoding.** Backports the fixed upstream decoder into a
  CommonJS compatibility build for Expo SDK 57, preventing malformed links
  from triggering the known recursive/quadratic decoding denial of service.
  Includes Expo SDK 57 patch updates and a rebuilt bundled web app.

Install the APK for your phone over the existing app: most phones use
`arm64-v8a`; older 32-bit phones use `armeabi-v7a`. The release workflow uses
the existing production signing key. Update the server with
`hermes plugins update winglet`, restart the gateway, and reload the web app.
Update both the app and server to use the new features.

Known limits: physical iPhone QA has not been completed. iPhone access remains
the HTTPS Safari/Home Screen web app; this release does not add native iOS or
TestFlight. A device offline for more than the 90-day deletion-retention window
can still retain previously cached deleted messages. Remaining dependency
advisories affect Expo build/config tooling and are tracked in the release review.
