# Winglet companion plugin

A small plugin for [Hermes Agent](https://github.com/NousResearch/hermes-agent) that runs on
your server and adds what the app needs:

- QR-code pairing for phones
- A registry of paired devices
- Push notifications for approvals, questions and finished results
  (Web Push for iPhone, ntfy for Android)
- Hosting for the web app

Coming in v0.1. See the [roadmap](../README.md#roadmap).
